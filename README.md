# Leli Rentals Monorepo

This repository contains the source code for the Leli Rentals platform, structured as a monorepo.

## Project Structure

- **`leli-rentals`**: The main user-facing application (Next.js).
- **`admin.leli.rentals`**: The admin dashboard application (Next.js).

## Deployment

This project is designed to be deployed on Vercel.

- **Main App**: Deploy the `leli-rentals` directory as the root.
- **Admin App**: Deploy the `admin.leli.rentals` directory as the root.
